# Profile README: how this repo works

This folder is the contents of `github.com/MiguelPimienta19/MiguelPimienta19`, the repo GitHub renders on the profile page.

    README.md                     generated by scripts/gen.py, do not hand-edit
    assets/geistmono.b64           Geist Mono woff2, embedded as a data URI in the ASCII cards
    assets/dark/*.svg             every card, dark theme
    assets/light/*.svg            every card, light theme (README swaps them with <picture>)
    data/contributions.json       written by the Action, real contribution counts
    scripts/gen.py                the only file to edit for copy, colors, layout
    scripts/fetch_contributions.py  no-token fetch of the public contribution calendar
    .github/workflows/tide.yml    daily at 09:17 UTC, refreshes data and SVGs, commits
    DESIGN.md                     the design position and what was deliberately cut
    HIGGSFIELD.md                 moodboard prompts for picking a palette

## Publish it

    cd ~/Documents/GitHub/MiguelPimienta19
    git init -b main
    git remote add origin git@github.com:MiguelPimienta19/MiguelPimienta19.git
    git fetch origin && git reset --soft origin/main     # keep the old history under the new files
    git add -A && git commit -m "profile: terminal README"
    git push -u origin main

Then open Actions on the repo and run "Refresh contributions" once by hand. Sample data is replaced by your real graph on that first run.

## Change something

Edit `scripts/gen.py`: `HEADLINES` for the typed line, `INFO` for the neofetch rows, `PROJECTS` for the work rows, `STACK`, `STEPS` for history, `SECTIONS` for the prompt strips, `THEMES` for colors. `DESIGN.md` records why the page is laid out the way it is. Then:

    python3 scripts/gen.py

Commit the regenerated `assets/` and `README.md`. GitHub caches images through camo for a while, so a change can take a few minutes to show.
